# 🌱 GrowZone
A fast‑paced, free‑to‑play browser game where you grow when still, shrink when moving, and try to survive inside an ever‑shrinking danger zone. Built for both desktop and mobile with responsive controls, smooth camera zoom, and simple AI bots to keep the world feeling alive.

This project is currently in active development — expect frequent updates, new mechanics, and improved gameplay polish.

---

## 🎮 Features
- **Free to play** — no downloads, no paywalls  
- **Mobile + Desktop support**  
- **Smooth camera system** that keeps your player readable at any size  
- **Dynamic bots** with mixed personalities  
- **Safe, randomly generated bot names**  
- **Player naming** with leaderboard visibility  
- **Shrinking danger zone** that forces movement  
- **Clean, mobile‑friendly leaderboard**  
- **Optimized for GitHub Pages hosting**

---

## 🕹️ Controls
### Desktop
- **WASD / Arrow Keys** — Move  
- **Stand still** — Grow  
- **Move** — Shrink  

### Mobile
- **Virtual joystick** appears automatically  
- Same grow/shrink mechanics
